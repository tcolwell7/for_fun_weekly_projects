**Overview**

This project was a small R exercise to keep my skills ticking along, purposefully done without AI assistance, relying only on what I remembered or could reuse from previous work. The analysis itself is straightforward: data wrangling, transformations, and summarising outputs for wider use. Nothing complex, but solid foundational work.

I also explored functionising repetitive steps so a user could generate their own outputs automatically rather than running everything interactively. Revisiting openxlsx was useful too — especially experimenting with styling and automated Excel report generation.

In summary, this project covered:

- Data wrangling with tidyverse

- Writing reusable functions for repeatable code

- Excel automation using openxlsx

All simple but practical skills that are genuinely useful in real analysis work.
