
**Overview**

This project was solely for me to scratch an itch I had exploring wider Scandi trade as I had noticed separately Sweden had a trade deficit which surprised me with the UK - so I wanted to extend this to the wider EU. Simply, this was a way for me to practice R, plots, creating useful functions on EU trade which I find interesting still 10 years following EU-exit. No surprises, besides Sweden now has a large trade deficit with the UK. 

**Covered in this project**

- Automated data processing
- Disseminating a lot a lot of data via ggplots
- gt tables

This was a for fun project which was interesting to look into UK-EU trade
