**Overview**

This project was for me to explore basic APIs using R. APIs weren't something I worked closely with in my previous role so this is something quite fresh for me. Simply, I started from scratch, read documentation and articles, use-cases and practical ways to extract data for real-world data analysis. While not a lot of code or analysis was created in this script, a lot f time was focused on learning, tutorials and figuring out why the APIs wouldn't work at first! However, I'm happy with this project and progress which I will use in my next project creating an API workflow. 

**Covered**

- Making basic API calls in R
- Handling both successful and unsuccessful responses
- Using an API (ONS Trade) to retrieve real trade data
- Automating multi‑parameter API calls
- Speeding up slow API workflows using parallel processing (furrr)
- Structuring API functions for reuse in analysis workflows
