**Overview**

I wanted to create a basic API workflow making use of extracted data to an output which could be used by others. This has been succeeded but due to the nature of data I was pulling (I was over optimistic about run times of pulling in larger amounts of data) the workflow was taking too long - so I decided to cut this short - however the purpose of this project has succeeded insofar:

- Successfully created API calls pulling in large amounts of data (albeit slower than hoped)
- Created an R workflow of data extraction, processing and dissemination through a (rough - do not judge) markdown report 
- Plots in R using ggplot again 
- Exploring more useful ways to store data for markdown documents (deframes() - rather than pre-calculate all values in a processing file). 

Purpose has been served so now time to move onto another project.
